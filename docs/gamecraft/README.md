# Gamecraft

What making worlds in this engine has taught, kept so the next run does not relearn it.

One file per topic, prose, no ceremony. Add to it at the end of a run: a mistake that cost an
hour, a shape that worked, a rule the CLI does not enforce and cannot. It is reviewed as an
ordinary commit, so write it and say you did.

The rule for what belongs here: **would a competent person, starting fresh, get this wrong?**
If yes, write it down. If it is in the CLI's refusal message already, do not — the refusal is
where it will actually be read.

| File | What is in it |
|---|---|
| `shopping-for-a-world.md` | Getting a map that suits the story before writing any of it |
| `scenes.md` | Cutscenes that are worth watching, and the ways they come out inert |
| `people.md` | Casting a town without writing thirty conversations |
| `failures.md` | Things that looked right, passed every check, and were wrong |
